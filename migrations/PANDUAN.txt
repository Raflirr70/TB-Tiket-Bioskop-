MIGRATIONS - DATABASE MIGRATIONS
==================================

Folder ini berisi file database migrations.

Cara Penggunaan:
----------------
Gunakan golang-migrate atau GORM AutoMigrate.

1. AutoMigrate (Development):
   db.AutoMigrate(&entity.User{}, &entity.Product{})

2. Manual Migration (Production):
   Buat file SQL di sini dengan format:
   000001_create_users_table.up.sql
   000001_create_users_table.down.sql

Contoh up.sql:
--------------
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

Contoh down.sql:
----------------
DROP TABLE IF EXISTS users;

Panduan:
--------
- Selalu buat migration UP dan DOWN.
- Gunakan angka urut di awal filename (000001, 000002, dll).
- Jangan edit migration yang sudah dijalankan di production.
- Test migration di development sebelum push ke production.
- Gunakan version control untuk semua perubahan schema.

INTERNAL/USECASE - IMPLEMENTASI USECASE
========================================

Folder ini berisi implementasi dari interface UseCase yang didefinisikan di domain.

File yang harus dibuat:
-----------------------
1. user_usecase.go
   - Struct UserUseCaseImpl dengan dependency UserRepository.
   - Mengimplementasi semua method dari domain/usecase/UserUseCase.
   - Berisi logika bisnis (validasi, transformasi, dll).

Contoh:
--------
package usecase

import (
    "errors"
    "yourproject/internal/domain/entity"
    "yourproject/internal/domain/repository"
)

type UserUseCaseImpl struct {
    userRepo repository.UserRepository
}

func NewUserUseCase(userRepo repository.UserRepository) *UserUseCaseImpl {
    return &UserUseCaseImpl{userRepo: userRepo}
}

func (uc *UserUseCaseImpl) GetUserByID(id int64) (*entity.User, error) {
    user, err := uc.userRepo.FindByID(id)
    if err != nil {
        return nil, errors.New("user not found")
    }
    return user, nil
}

func (uc *UserUseCaseImpl) CreateUser(user *entity.User) error {
    // Logika validasi bisnis di sini
    if user.Name == "" {
        return errors.New("name is required")
    }
    return uc.userRepo.Create(user)
}

Panduan:
--------
- Implementasi HARUS mengikuti interface dari domain/usecase/.
- Logika bisnis (validasi aturan, transformasi data) ada di sini.
- Panggil repository untuk operasi data.
- Jangan import handler atau delivery layer.
- Return error yang jelas dan deskriptif.
- Jangan langsung terhubung ke database, selalu melalui repository.

INTERNAL/CONFIG - KONFIGURASI APLIKASI
=======================================

Folder ini berisi pengelolaan konfigurasi aplikasi.

File yang harus dibuat:
-----------------------
1. config.go
   - Struct Config yang menampung semua konfigurasi.
   - Fungsi Load() atau NewConfig() untuk membaca dari env/file.
   - Menggunakan package seperti viper, godotenv, atau os.Getenv.

2. (Opsional) database.go
   - Konfigurasi spesifik untuk database (host, port, user, pass, dbname).

3. (Opsional) redis.go
   - Konfigurasi untuk Redis/cache.

Contoh Struct:
--------------
type Config struct {
    ServerPort string
    DBHost     string
    DBPort     string
    DBUser     string
    DBPassword string
    DBName     string
    RedisAddr  string
    JWTSecret  string
}

func Load() *Config {
    // Load from .env or environment variables
}

Panduan:
--------
- Selalu gunakan environment variable (12-Factor App).
- Jangan hardcode secrets di source code.
- Sediakan file .env.example sebagai template.
- Gunakan godotenv untuk load .env di development.

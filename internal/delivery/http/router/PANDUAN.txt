INTERNAL/DELIVERY/HTTP/ROUTER - ROUTE DEFINITIONS
===================================================

Folder ini berisi definisi route/routing untuk semua endpoint API.

File yang harus dibuat:
-----------------------
1. router.go
   - Fungsi NewRouter() yang setup semua routes.
   - Menginisialisasi handler dan mendaftarkan route.
   - Menggunakan Gin engine.

2. user_route.go (opsional, bisa digabung di router.go)
   - Route spesifik untuk user feature.

Contoh:
--------
package router

import (
    "github.com/gin-gonic/gin"
    "yourproject/internal/delivery/http/handler"
    "yourproject/internal/delivery/http/middleware"
)

func NewRouter(userHandler *handler.UserHandler) *gin.Engine {
    r := gin.Default()

    // Middleware
    r.Use(middleware.CORS())
    r.Use(middleware.Logger())

    // API v1
    v1 := r.Group("/api/v1")
    {
        users := v1.Group("/users")
        {
            users.GET("", userHandler.GetAllUsers)
            users.GET("/:id", userHandler.GetUser)
            users.POST("", userHandler.CreateUser)
            users.PUT("/:id", userHandler.UpdateUser)
            users.DELETE("/:id", userHandler.DeleteUser)
        }
    }

    return r
}

Panduan:
--------
- Group routes berdasarkan versi API (/api/v1, /api/v2).
- Gunakan middleware (auth, CORS, logger) di router level.
- Nama route harus RESTful:
  * GET    /users       -> GetAllUsers
  * GET    /users/:id   -> GetUser
  * POST   /users       -> CreateUser
  * PUT    /users/:id   -> UpdateUser
  * DELETE /users/:id   -> DeleteUser
- Jangan letakkan logika bisnis di sini, hanya routing.

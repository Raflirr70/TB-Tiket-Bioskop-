INTERNAL/DELIVERY/HTTP/MIDDLEWARE - HTTP MIDDLEWARE
====================================================

Folder ini berisi middleware untuk HTTP server.

File yang harus dibuat:
-----------------------
1. cors.go
   - Middleware untuk CORS (Cross-Origin Resource Sharing).

2. auth.go
   - Middleware untuk autentikasi (JWT / API Key).
   - Validasi token dan inject user info ke context.

3. logger.go
   - Middleware untuk logging request dan response.

4. rate_limiter.go (opsional)
   - Middleware untuk rate limiting.

Contoh:
--------
package middleware

import (
    "net/http"
    "github.com/gin-gonic/gin"
)

func CORS() gin.HandlerFunc {
    return func(c *gin.Context) {
        c.Writer.Header().Set("Access-Control-Allow-Origin", "*")
        c.Writer.Header().Set("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS")
        c.Writer.Header().Set("Access-Control-Allow-Headers", "Content-Type, Authorization")
        
        if c.Request.Method == "OPTIONS" {
            c.AbortWithStatus(http.StatusNoContent)
            return
        }
        
        c.Next()
    }
}

Panduan:
--------
- Middleware berada di delivery layer, bukan di domain.
- Setiap middleware harus independent dan reusable.
- Jangan letakkan logika bisnis di middleware.
- Auth middleware harus validasi token dan inject user ke gin.Context.
- Gunakan c.Set() untuk menyimpan data di context, c.Get() untuk mengambil.

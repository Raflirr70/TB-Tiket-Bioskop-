INTERNAL/REPOSITORY - IMPLEMENTASI REPOSITORY
==============================================

Folder ini berisi implementasi dari interface Repository yang didefinisikan di domain.

File yang harus dibuat:
-----------------------
1. user_repository.go
   - Struct UserRepositoryImpl dengan dependency *gorm.DB.
   - Mengimplementasi semua method dari domain/repository/UserRepository.
   - Query database menggunakan GORM atau raw SQL.

Contoh:
--------
package repository

import (
    "yourproject/internal/domain/entity"
    "gorm.io/gorm"
)

type UserRepositoryImpl struct {
    db *gorm.DB
}

func NewUserRepository(db *gorm.DB) *UserRepositoryImpl {
    return &UserRepositoryImpl{db: db}
}

func (r *UserRepositoryImpl) FindByID(id int64) (*entity.User, error) {
    var user entity.User
    err := r.db.First(&user, id).Error
    if err != nil {
        return nil, err
    }
    return &user, nil
}

func (r *UserRepositoryImpl) Create(user *entity.User) error {
    return r.db.Create(user).Error
}

Panduan:
--------
- Implementasi HARUS mengikuti interface dari domain/repository/.
- Di sini boleh pakai GORM, database/sql, atau raw SQL.
- Handle error dari database dan return ke usecase.
- Jangan letakkan logika bisnis, hanya operasi data.
- Nama file harus sesuai: user_repository.go untuk UserRepository.
- Inject database via constructor (NewXxxRepository).

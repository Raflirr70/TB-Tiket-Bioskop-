PKG/RESPONSE - STANDARD RESPONSE FORMAT
=========================================

Folder ini berisi helper untuk format response API yang konsisten.

File yang harus dibuat:
-----------------------
1. response.go
   - Fungsi Success() untuk response sukses.
   - Fungsi Error() untuk response error.
   - Struct standar untuk response format.

Contoh:
--------
package response

import "github.com/gin-gonic/gin"

type APIResponse struct {
    Code    int         `json:"code"`
    Message string      `json:"message"`
    Data    interface{} `json:"data,omitempty"`
}

type PaginatedResponse struct {
    Code    int         `json:"code"`
    Message string      `json:"message"`
    Data    interface{} `json:"data"`
    Total   int64       `json:"total"`
    Page    int         `json:"page"`
    Limit   int         `json:"limit"`
}

func Success(c *gin.Context, statusCode int, data interface{}) {
    c.JSON(statusCode, APIResponse{
        Code:    statusCode,
        Message: "success",
        Data:    data,
    })
}

func Error(c *gin.Context, statusCode int, message string) {
    c.JSON(statusCode, APIResponse{
        Code:    statusCode,
        Message: message,
    })
}

func Paginated(c *gin.Context, statusCode int, data interface{}, total int64, page, limit int) {
    c.JSON(statusCode, PaginatedResponse{
        Code:    statusCode,
        Message: "success",
        Data:    data,
        Total:   total,
        Page:    page,
        Limit:   limit,
    })
}

Panduan:
--------
- Selalu gunakan helper ini di handler untuk response yang konsisten.
- Format JSON harus selalu punya field: code, message, data.
- Untuk paginated response, sertakan total, page, dan limit.
- HTTP status code harus sesuai:
  * 200 OK
  * 201 Created
  * 400 Bad Request
  * 401 Unauthorized
  * 403 Forbidden
  * 404 Not Found
  * 500 Internal Server Error

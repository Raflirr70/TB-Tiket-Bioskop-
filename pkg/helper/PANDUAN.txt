PKG/HELPER - UTILITY FUNCTIONS
================================

Folder ini berisi helper functions yang dipakai di seluruh aplikasi.

Isi yang bisa dimasukkan:
--------------------------
1. password.go
   - Hash password (bcrypt).
   - Compare password.

2. jwt.go
   - Generate JWT token.
   - Validate JWT token.
   - Parse JWT claims.

3. uuid.go
   - Generate UUID.

4. time.go
   - Helper untuk format waktu.

Contoh (password.go):
----------------------
package helper

import "golang.org/x/crypto/bcrypt"

func HashPassword(password string) (string, error) {
    bytes, err := bcrypt.GenerateFromPassword([]byte(password), 14)
    return string(bytes), err
}

func CheckPassword(password, hash string) bool {
    err := bcrypt.CompareHashAndPassword([]byte(hash), []byte(password))
    return err == nil
}

Panduan:
--------
- Helper harus PURE FUNCTION tanpa side effect.
- Jangan import domain entity atau repository di sini.
- Setiap helper harus punya nama file yang jelas sesuai fungsinya.
- Helper harus bisa dipakai di mana saja dalam aplikasi.
- Jangan letakkan logika bisnis spesifik feature di sini.

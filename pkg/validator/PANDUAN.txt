PKG/VALIDATOR - INPUT VALIDATION
==================================

Folder ini berisi custom validator untuk validasi input.

File yang harus dibuat:
-----------------------
1. validator.go
   - Custom validation rules yang sering dipakai.
   - Init validator instance (package go-playground/validator).

Contoh:
--------
package validator

import (
    "github.com/go-playground/validator/v10"
)

var validate *validator.Validate

func init() {
    validate = validator.New()
    
    // Custom validation
    validate.RegisterValidation("password", ValidatePassword)
}

func Validate(data interface{}) error {
    return validate.Struct(data)
}

func ValidatePassword(fl validator.FieldLevel) bool {
    password := fl.Field().String()
    return len(password) >= 8
}

Contoh penggunaan di handler:
-----------------------------
type CreateUserRequest struct {
    Name     string `json:"name" validate:"required,min=3,max=50"`
    Email    string `json:"email" validate:"required,email"`
    Password string `json:"password" validate:"required,password"`
}

Panduan:
--------
- Gunakan struct tag `validate` untuk validasi.
- Custom validator untuk aturan bisnis (password strength, dll).
- Validasi dilakukan di handler atau usecase (tergantung kebutuhan).
- Return error yang jelas agar client tahu field mana yang salah.
- Jangan validasi di repository atau entity.

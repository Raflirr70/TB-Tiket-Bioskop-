TEMPLATES/LAYOUTS - BASE LAYOUT TEMPLATE
==========================================

Folder ini berisi template layout utama yang membungkus semua halaman.

File yang harus dibuat:
-----------------------
1. base.html
   - Template dasar yang di-extend oleh semua halaman.
   - Berisi: <!DOCTYPE html>, <head>, <body>, navbar, footer.
   - Menggunakan Go template syntax.

Contoh base.html:
------------------
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{{ .Title }}</title>
    <link rel="stylesheet" href="/static/css/style.css">
    <link rel="stylesheet" href="/static/css/components.css">
</head>
<body>
    {{ template "navbar" . }}
    
    <main class="container">
        {{ template "content" . }}
    </main>
    
    {{ template "footer" . }}
    
    <script src="/static/js/app.js"></script>
</body>
</html>

Panduan:
--------
- Gunakan {{ template "content" . }} sebagai placeholder untuk konten halaman.
- Semua halaman harus extend base.html.
- Letakkan CSS di <head>, JavaScript di akhir <body>.
- Sertakan meta tags pentifkasi: charset, viewport, description.
- Gunakan {{ .Title }} untuk dynamic title per halaman.
- Navbar dan footer di-import sebagai partials.

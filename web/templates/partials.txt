TEMPLATES/PARTIALS - REUSABLE COMPONENTS
==========================================

Folder ini berisi template HTML yang bisa di-reuse di banyak halaman.

File yang harus dibuat:
-----------------------
1. navbar.html
   - Navigasi bar utama (logo, menu, logout button).

2. footer.html
   - Footer website (copyright, links).

3. sidebar.html
   - Sidebar navigation (jika ada).

4. pagination.html
   - Komponen pagination untuk list data.

5. alert.html
   - Flash messages / notifications (success, error, warning).

6. form_field.html
   - Reusable form fields (text input, select, textarea).

Contoh navbar.html:
-------------------
{{ define "navbar" }}
<nav class="navbar">
    <div class="navbar-brand">
        <a href="/">MyApp</a>
    </div>
    <ul class="navbar-menu">
        <li><a href="/">Home</a></li>
        <li><a href="/users">Users</a></li>
    </ul>
    <div class="navbar-actions">
        {{ if .IsLoggedIn }}
            <span>{{ .UserName }}</span>
            <a href="/logout">Logout</a>
        {{ else }}
            <a href="/login">Login</a>
        {{ end }}
    </div>
</nav>
{{ end }}

Panduan:
--------
- Setiap partial harus di-wrap dengan {{ define "nama" }}...{{ end }}.
- Partial di-import di base.html atau page lain: {{ template "navbar" . }}.
- Beri nama file yang jelas sesuai fungsinya.
- Jangan terlalu panjang, pecah menjadi partial kecil jika >50 baris.
- Data dari parent template bisa diakses langsung ({{ .FieldName }}).

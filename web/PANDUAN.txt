WEB - FRONTEND ASSETS
======================

Folder ini berisi semua file frontend (HTML, CSS, JavaScript).

Struktur:
---------
web/
  static/             -> Static assets yang di-serve langsung oleh Gin
    css/                -> Stylesheet files
    js/                 -> JavaScript files
    img/                -> Gambar (icons, logos, photos)
    fonts/              -> Custom fonts (Google Fonts, Font Awesome)
  
  templates/          -> HTML templates (server-side rendering)
    layouts/            -> Template layout utama (base template)
    pages/              -> Halaman HTML per page
    partials/           -> Component HTML yang bisa di-reuse
  
  assets/             -> Raw assets (source files, SCSS, TypeScript)

Cara Pakai di Gin:
------------------
1. Static files:
   r.Static("/static", "./web/static")

2. Templates:
   r.LoadHTMLGlob("web/templates/**/*")

3. Render page:
   c.HTML(200, "index.html", data)

Dependency Rule:
-----------------
- CSS dan JS di-import ke dalam HTML templates.
- Static assets di-serve langsung tanpa processing.
- Templates menggunakan Go template syntax ({{ .Title }}).

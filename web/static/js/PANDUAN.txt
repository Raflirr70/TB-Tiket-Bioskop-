STATIC/JS - JAVASCRIPT FILES
==============================

Folder ini berisi semua file JavaScript untuk interaksi frontend.

File yang harus dibuat:
-----------------------
1. app.js
   - File utama JavaScript.
   - Inisialisasi aplikasi, event listeners global, helper functions.

2. api.js
   - Fungsi untuk melakukan fetch/axios call ke backend API.
   - Contoh: fetchUsers(), createUser(data), updateUser(id, data).

3. components.js
   - Fungsi untuk membuat/re-render komponen UI.
   - Contoh: renderUserCard(user), renderPagination(total, page).

4. (Opsional) auth.js
   - Fungsi autentikasi: login, logout, token management.

5. (Opsional) validator.js
   - Client-side validation sebelum mengirim ke server.

Contoh api.js:
--------------
const API_BASE = '/api/v1';

async function fetchUsers(page = 1, limit = 10) {
    const response = await fetch(`${API_BASE}/users?page=${page}&limit=${limit}`);
    if (!response.ok) throw new Error('Failed to fetch users');
    return response.json();
}

async function createUser(data) {
    const response = await fetch(`${API_BASE}/users`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(data)
    });
    if (!response.ok) throw new Error('Failed to create user');
    return response.json();
}

Panduan:
--------
- Gunakan fetch API (native) atau axios untuk HTTP requests.
- Pisahkan logic: api.js (data), components.js (UI), app.js (glue).
- Handle error dengan try-catch dan tampilkan pesan ke user.
- Gunakan async/await, jangan callback nesting.
- Jangan hardcode URL API, gunakan const BASE_URL.
- Untuk SPA, pertimbangkan menggunakan Alpine.js atau htmx.

STATIC/CSS - STYLESHEET FILES
===============================

Folder ini berisi semua file CSS untuk styling halaman web.

File yang harus dibuat:
-----------------------
1. style.css
   - CSS utama untuk seluruh aplikasi.
   - Berisi custom properties (CSS variables), base styles, layout.

2. components.css
   - CSS untuk reusable components (buttons, cards, forms, modals).

3. responsive.css
   - Media queries untuk responsive design (mobile, tablet, desktop).

4. (Opsional) animate.css
   - Custom animations dan transitions.

Panduan Penulisan:
------------------
- Gunakan CSS Variables untuk konsistensi warna, font, spacing:
  :root {
    --primary-color: #007bff;
    --font-family: 'Inter', sans-serif;
    --spacing-sm: 8px;
    --spacing-md: 16px;
    --border-radius: 8px;
  }

- Ikuti BEM naming convention untuk selector:
  .card { }
  .card__title { }
  .card__body { }
  .card--active { }

- Pisahkan file berdasarkan kebutuhan:
  * style.css     -> Base & layout
  * components.css -> Component styles
  * responsive.css -> Media queries

- Jangan gunakan !important kecuali benar-benar perlu.
- Urutkan selector dari umum ke spesifik.
- Komentari bagian-bagian besar untuk kemudahan maintenance.
